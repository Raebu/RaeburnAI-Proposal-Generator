# Product Screenshots & Visual Presentation Guide

The **RaeburnAI Proposal Generator** features an executive consultant workspace designed for commercial credibility.

## Captured UI Views & Component Layouts

1. **Header & Context Bar**:

   - Branding: Raeburn Consulting Group
   - Indicator: Commercial Engine • Strict Schema Validation • Contract 1.0
   - Action: ⚡ Load Demo Client Data

2. **Client & Context Input Form**:

   - Fields: Client Name, Sector, Company Size, Website Excerpts, LinkedIn & Annual Report Notes, Current Pain & Bottlenecks, Desired Outcome, Stated Budget Range, Timeline Preference.
   - Deterministic ROI Calculator Inputs: Affected Staff Count, Hours Saved/Wk, Hourly Rate (£/hr), Investment Benchmark (£).

3. **Commercial Proposal Output View**:
   - Status Badge: `DRAFT_REQUIRES_HUMAN_REVIEW`
   - Actions: 📋 Copy Text, 💾 JSON Export, 🖨️ Print / PDF Export
   - Rendered Sections:
     1. Executive Summary
     2. Business Context & Strategic Alignment
     3. Current State Assessment
     4. Operational Challenges & Prioritised Opportunities
     5. Core Engagement Proposal Scope
     6. Technical Solution & AI Architecture
     7. Phased Implementation Roadmap
     8. Commercial Pricing Tiers
     9. Delivery Timeline & Workstream Table
     10. Deterministic ROI & Financial Payback Breakdown
     11. Risk Register & Mitigations Table
     12. Governance Framework & Responsible AI Guidelines
     13. Recommended Next Steps
     14. Executive Presentation Outline (5-Slide Pitch Deck)

## PDF & Print Export View

The interface includes a dedicated `@media print` CSS stylesheet. When selecting **🖨️ Print / PDF**, navigation controls and dark form panels are automatically hidden (`no-print`), rendering a clean, document-styled white proposal suitable for PDF saving or client distribution.
